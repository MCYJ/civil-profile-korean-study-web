CONCEPT GUIDE / 01

계산을 읽는 세 가지 순서

  1. 거리는 수평 누가거리인지 확인합니다. 표고는 모두 같은 기준면을 사용합니다.
  2. 각 구간의 표고차를 수평거리로 나눠100을 곱합니다. 음수는 진행 방향의 내리막입니다.
  3. 전체는 끝점의 표고차/전체 수평거리×100입니다. 두 구간 백분율을 단순평균하지 않습니다.

이 페이지의 세 측점은 직접 만든 작은 예제입니다. 예를 들어 A(0m,100m), B(20m,101m), C(100m,102m)라면 첫 구간5%, 다음 구간1.25%, 전체2%입니다. 두 구간의 단순평균3.125%와 구분하세요.

도식의 세로 축을 강조하면 선의 화면 각도는 달라집니다. 표시 각도를 실제 기울기로 읽지 마세요. 이 페이지와 앱의 입력 범위는 학습 모델의 한계이며 설계 허용 기준이 아닙니다.

기본 기울기 정의의 산술 검토에 FHWA 자료를 참고했습니다. 미국 도로 설계 기준을 한국 시험 기준으로 적용하지 않습니다.
