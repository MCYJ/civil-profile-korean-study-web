자주 묻는 질문

소개문이 영어면 문제도 영어인가요?

아닙니다. 웹은 한국어·영어를 제공하지만 앱 화면·문제·해설은 한국어입니다. 스토어 소개문의 번역 언어와 실제 학습 언어를 구분합니다.

구독이나 추가 결제가 필요한가요?

준비 중인 앱은 설치 전 스토어에서 한 번 결제하는 유료 다운로드 방식입니다. 포함된 학습에 월 구독·추가 앱 내 잠금 해제 결제·일일 무료 문항 제한을 요구하지 않습니다. 현재 웹에는 구매 링크가 없습니다.

인터넷 없이 무엇을 이용하나요?

설치 후 포함된 문제·해설·개념·그림·복습·학습기록을 이용합니다. 구매·다운로드·재다운로드·업데이트와 외부 공식·정책 링크에는 연결이 필요할 수 있습니다. 알림은 권한과 기기 설정에 따릅니다.

A/B는 자동으로 덮어쓰나요?

새 종단선 실습의 현재 편집과 저장 A/B는 따로 유지됩니다. 저장 버튼으로 기록한 사례만 해당 슬롯이 바뀝니다. 다른 사례를 불러와도 보관한 A/B가 자동 변경되지는 않습니다.

공식 CAD·실기 채점 도구인가요?

아닙니다. 가상 세 측점을 두 직선으로 연결하는 제한된 개념 모델입니다. 수직곡선·지형 보정·KS/KDS 설계 적합 판정·공식 실기 채점은 제공하지 않습니다.

앱 삭제 후 학습기록을 복원할 수 있나요?

운영자가 복원하는 계정·서버 동기화 기능을 제공하지 않습니다. 기기 변경이나 삭제 전에 필요한 기록을 확인하세요. 문제가 있으면 지원 페이지의 연락처로 앱 버전과 재현 순서를 알려주세요.
