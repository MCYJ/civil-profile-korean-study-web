From a short session to review

1. Start a short session

Start the ten-question session from Home, read a prompt and choose an answer. Review the explanation and included figure after answering. The paid-download model allows another session after ten questions.

Bookmark questions and return to saved items or study history from the menu. Records use local storage without an account or server synchronization.

3. Connect concepts and values

Read concept diagrams, then compare how changes in distance and elevation affect segment grades in the new station/profile workshop. Saved A/B cases remain separate from current edits.

4. Notifications are optional

Enable study notifications only if you want them and grant device permission. Question content is private by default. Store installation, updates and external links may require connectivity.
