CONCEPT GUIDE / 01

Three steps for reading grade

  1. Confirm that distance is cumulative horizontal run. Use a common elevation datum for all stations.
  2. For each segment, divide elevation change by horizontal run and multiply by 100. A negative value indicates descent along the stated direction.
  3. Overall grade uses end-to-end elevation change / total horizontal run ×100, rather than the simple mean of segment percentages.

These three stations are small authored examples. For A(0m,100m), B(20m,101m) and C(100m,102m), the first segment is 5%, the next is 1.25% and the overall grade is 2%. Their simple mean, 3.125%, is different.

Vertical exaggeration changes the displayed angle of the line. Do not read that screen angle as actual grade. These learning-model input limits are not engineering design allowances.

The FHWA reference supports the basic arithmetic definition of grade. It is not adopted here as a Korean exam or engineering design rule.
