# Civil Drafting Study

Independent Korean exam-study app support and concept website by RushLabs.

Public site: https://mcyj.github.io/civil-profile-korean-study-web/ko/

Static GitHub Pages source in `docs/`, with Korean/English home, concept guide, support and privacy pages. The small web example is original illustrative material, not an app screenshot, official exam task or CAD/design compliance tool. The app is preparing for release; app UI and study content are Korean. No private question bank, credentials, analytics or application user data is included.

The website now provides18 localized pages: home, ten-topic concept guide, features, study flow, official exam information, FAQ, usage/store terms, support and privacy in Korean/English. Screenshots from the new native candidate are pending runtime validation and are not substituted with the web example.
